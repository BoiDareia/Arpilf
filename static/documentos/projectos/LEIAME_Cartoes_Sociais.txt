    Cartoes_Sociais.pdf

Passos:
  1. Copiar o PDF para:
     static/documentos/projectos/Cartoes_Sociais.pdf
  2. (Opcional) Comprimir se for grande, como foi feito com a ficha
     da Distribuição Direta.
  3. Apagar este ficheiro LEIAME.
  4. git add, commit e push — o site publica automaticamente no merge.
